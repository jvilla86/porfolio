Cómo crear tus propios comandos en Linux

Un ejemplo sencillo de cómo crear tus propios comandos para ejecutar en terminal de Linux.

Todos sabemos que si hay algo que caracteriza a los usuarios de Linux, es el uso de la terminal. Es cierto que hoy en día, las distintas distribuciones de Linux han abrazado entornos gráficos para que la experiencia de usuario no diste mucho del uso de Windows o MacOS. Y perfectamente se puede contar con casi cualquier distribución de Linux en tu PC sin tocar la terminal.

Sin embargo, profundizar en el uso de terminal se antoja casi imprescindible si deseas sacar todo el partido a tu ordenador. O muchas veces, se trata de buenas prácticas ya sea en cuanto a instalar o desinstalar aplicaciones o en la gestión de procesos y archivos de tu ordenador.

Y en el uso de comandos, muchas veces ocurre que, o bien nos vemos obligados a realizar una combinación concreta de forma constante, o bien, tenemos que memorizar comandos que apenas recordamos y que tenemos que buscar cada vez en buscadores o en documentación. Pues para esto mismo está la opción de crear tus propios alias que representen distintas combinaciones de comandos pero llamándoles como a ti te parezca mejor.

Al escribir el alias concreto en terminal y pulsar enter, se ejecutarán todos los comandos que hayas indicado que equivalgan a dicho alias.

Por ejemplo, vamos a crear un alias que inicializa el entorno virtual concreto de un directorio donde tenemos scripts de python y, tras esto, ejecuta un script concreto. Así, con un solo comando, podremos ejecutar varias acciones.

Para ello, tenemos que editar el archivo ~/.bashrc o ~/.zshrc dependiendo de cual sea tu terminal (bash o zsh). En mi caso, lo haré para zsh:

echo "alias miscript='cd ~/proyectos/ & source venv/bin/activate & python miprograma.py" >> ~/.zshrc
source ~./zshrc

Con el echo, insertamos directamente esa línea en el archivo ~./zshrc. Esa línea ejecuta tres comandos, primero nos situamos en el directorio proyectos. Acto seguido, inicializamos el entorno virtual de python para ese directorio concreto. Y tras ello, ejecutamos miprograma.py. Luego, tenemos que reiniciar la terminal con el comando source.

De esta forma, cuando tecleamos miscript, llevará a cabo esas tres funciones con un solo comando.
