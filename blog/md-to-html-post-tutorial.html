Automatiza tu Blog Minimalista: Convierte Markdown a HTML con Python

Escribir directamente en HTML cuando gestionas un sitio web estático puede volverse tedioso y lento. Lo ideal es separar el contenido de la estructura visual: redactar cómodamente en Markdown (.md) y dejar que un script se encargue de inyectar esas notas dentro de tu plantilla corporativa.

En este tutorial veremos cómo construir un script en Python muy ligero que automatiza todo este proceso en local para tu repositorio. Así es como yo lo hago para esta web justamente.

1. Requisitos previos y dependencias

Para compilar Markdown desde Python de forma eficiente, utilizaremos la biblioteca oficial markdown. Asegúrate de tenerla instalada en tu entorno (por ejemplo, en Manjaro Linux) ejecutando el siguiente comando en tu terminal:

pip install markdown

Estructura tu proyecto de manera que tengas una carpeta content/ para tus borradores en Markdown y una carpeta blog/ donde se almacene tu archivo plantilla-articulo.html.

2. El Script de Automatización (build_blog.py)

Crea un archivo llamado build_blog.py en la raíz de tu proyecto con el siguiente código base. Este script leerá automáticamente todos los archivos .md, extraerá sus metadatos principales, los convertirá a HTML estructurado y los volcará en la carpeta del blog:

import os
import re
import markdown

CONTENT_DIR = "content"
BLOG_DIR = "blog"
TEMPLATE_FILE = os.path.join(BLOG_DIR, "plantilla-articulo.html")

def build_posts():
    if not os.path.exists(CONTENT_DIR):
        os.makedirs(CONTENT_DIR)
        print(f"Se ha creado la carpeta '{CONTENT_DIR}'. Pon ahí tus archivos .md")
        return

    if not os.path.exists(TEMPLATE_FILE):
        print(f"Error: No se encuentra la plantilla en {TEMPLATE_FILE}")
        return

    # Leer la plantilla base del blog
    with open(TEMPLATE_FILE, "r", encoding="utf-8") as f:
        template = f.read()

    md_files = [f for f in os.listdir(CONTENT_DIR) if f.endswith(".md")]
    if not md_files:
        print(f"No hay archivos .md en la carpeta '{CONTENT_DIR}/'.")
        return

    for file in md_files:
        md_path = os.path.join(CONTENT_DIR, file)
        with open(md_path, "r", encoding="utf-8") as f:
            md_content = f.read()

        # Extraer metadatos superiores (Frontmatter básico)
        lines = md_content.split("\n")
        metadata = {}
        content_lines = []
        
        is_metadata = True
        for line in lines:
            if is_metadata:
                if ":" in line:
                    key, val = line.split(":", 1)
                    metadata[key.strip().lower()] = val.strip()
                elif line.strip() == "":
                    is_metadata = False
                continue
            content_lines.append(line)
        
        clean_md = "\n".join(content_lines)
        
        # Convertir Markdown a HTML con soporte para tablas y bloques de código
        html_body = markdown.markdown(clean_md, extensions=['fenced_code', 'tables'])

        title = metadata.get("titulo", "Artículo sin título")
        description = metadata.get("descripcion", "")
        
        post_html = template

        # Remplazar elementos clave de SEO en la plantilla
        post_html = re.sub(r"<title>.*?</title>", f"<title>{title} | José Villa</title>", post_html)
        post_html = re.sub(r'<meta name="description" content=".*?">', f'<meta name="description" content="{description}">', post_html)
        post_html = re.sub(r'<h1>.*?</h1>', f'<h1>{title}</h1>', post_html, count=1)
        
        # Inyectar el cuerpo del artículo en la etiqueta de la plantilla
        if "<!-- CONTENT -->" in post_html:
            post_html = post_html.replace("<!-- CONTENT -->", html_body)

        html_filename = file.replace(".md", ".html")
        html_output_path = os.path.join(BLOG_DIR, html_filename)

        with open(html_output_path, "w", encoding="utf-8") as f:
            f.write(post_html)

        print(f"¡Compilado con éxito!: {file} -> blog/{html_filename}")

if __name__ == "__main__":
    build_posts()

3. Preparación de la Plantilla HTML

Para que el script sepa exactamente dónde colocar el texto generado a partir del Markdown, añade la siguiente marca de comentario dentro del cuerpo principal de tu archivo plantilla-articulo.html:

<main class="contenedor-articulo">
    <h1>Título por defecto</h1>
    <!-- CONTENT -->
</main>

4. Flujo de trabajo diario

Una vez configurado el entorno, redactar un nuevo artículo se convierte en una tarea de tres simples pasos:

  • Escribe tu artículo en formato .md dentro de la carpeta content/.
  • Ejecuta el script de compilación en tu terminal: 
    python build_blog.py
  • Sube los cambios generados a tu repositorio usando Git: 
    git add .
git commit -m "feat: añadir nuevo artículo generado automáticamente"
git push origin main

De esta forma mantienes un entorno limpio, desacoplado y optimizado para la creación de contenido web estático.
