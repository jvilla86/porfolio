Cómo convertir Markdown a HTML con Python (Tutorial Sencillo)

Gestionar un sitio web estático escribiendo código HTML puro desde cero puede volverse repetitivo y poco práctico. La solución ideal es separar el contenido de la estructura visual: redactar cómodamente en Markdown (.md) y dejar que un script de Python se encargue de compilarlo en páginas web listas para producción.

En este artículo veremos cómo construir un script minimalista, fácil de entender y adaptar a cualquier proyecto web personal.

1. Instalación de dependencias

Para traducir sintaxis Markdown a etiquetas HTML de forma limpia, utilizaremos la biblioteca oficial markdown. Si trabajas en entornos como Linux (por ejemplo, Manjaro o Ubuntu), instálala rápidamente ejecutando el siguiente comando en tu terminal:

pip install markdown

2. El script de automatización esencial

Crea un archivo llamado build.py en la raíz de tu proyecto. Este script busca tus archivos Markdown, los procesa y los inyecta dentro de una plantilla HTML corporativa:

import os

import markdown

CONTENT_DIR = "content"
OUTPUT_DIR = "blog"
TEMPLATE_FILE = os.path.join(OUTPUT_DIR, "plantilla-articulo.html")

def compilar_blog():
# 1. Leer la plantilla base
if not os.path.exists(TEMPLATE_FILE):
print("Error: No se encuentra la plantilla HTML.")
return

with open(TEMPLATE_FILE, "r", encoding="utf-8") as f:
    plantilla = f.read()

# 2. Buscar y procesar cada archivo Markdown
for archivo in os.listdir(CONTENT_DIR):
    if archivo.endswith(".md"):
        ruta_md = os.path.join(CONTENT_DIR, archivo)
        
        with open(ruta_md, "r", encoding="utf-8") as f:
            contenido_md = f.read()

        # Convertir Markdown a HTML estándar
        html_generado = markdown.markdown(contenido_md, extensions=['fenced_code', 'tables'])

        # Inyectar el resultado en la plantilla
        articulo_final = plantilla.replace("<!-- CONTENT -->", html_generado)

        # Guardar el resultado como un nuevo archivo HTML
        nombre_salida = archivo.replace(".md", ".html")
        ruta_salida = os.path.join(OUTPUT_DIR, nombre_salida)

        with open(ruta_salida, "w", encoding="utf-8") as f:
            f.write(articulo_final)

        print(f"¡Compilado con éxito: {archivo} -> {nombre_salida}!")

3. ¿Por qué utilizar este enfoque?


    
    
        
  • Simplicidad absoluta: El script tiene pocas líneas y no requiere configuraciones complejas de bases de datos.
    • 
        
  • Portabilidad total: Al generar archivos .html estáticos, puedes alojarlos de forma gratuita y ultrarrápida en GitHub Pages o Cloudflare Pages.
    • 
        
  • Control local: Tus textos viven en tu ordenador en formato de texto plano, facilitando las copias de seguridad con Git.
